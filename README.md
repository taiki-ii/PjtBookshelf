#  プロジェクト名
社会人、学生のプロジェクト本棚メモ管理アプリ

【概要】</br>
社会人、学生の自己課題（プロジェクト）の管理支援をします！</br>
具体的には、自己課題である「プロジェクト」毎に「本棚」を作成して、使用した「本」と「メモ」を管理します</br>
【目的】</br>
常に、作業に取り掛かりやすい状態を作る</br>
【対象者】</br>
社会人、学生</br>
【対象物】</br>
自己課題（技術学習、大学でのレポート作成、資格勉強、プレゼン作成、ポートフォリオ作成、学習発表、日々のスキル学習・・・）</br>
【背景】</br>
小さな管理負担をなくして、作業に取り掛かりやすい状態を作りたいと考え、本アプリを作成開始しました！</br>
エンジニア歴1年経ち、研鑽のために個人開発を始めたいと思ったことも理由です！</br>
-マーカーを引いた箇所を見直すことが大変、メモを分類できない、引用で使用した本をすぐにコピペしたい等、作業が増えるほど管理したいものが増えてしまいませんか？</br>
-小さな探しものが増えて、時間を消費してしまうことがよくありませんか？（私はよくあります・・・））</br>

#   機能
■認証</br>
・ログイン</br>
・ログアウト</br>
・ユーザー新規登録 </br>
■プロジェクト</br>
・プロジェクト作成 </br>
・プロジェクト一覧表示 </br>
・プロジェクト詳細表示 </br>
・プロジェクト名変更 </br>
・プロジェクト削除 </br>
■本
・本を検索する   ※Google Books Api使用</br>
・本をプロジェクトに登録 </br>
・登録済み本を表示</br>
・本の詳細表示</br>
・本の削除 </br>
■メモ</br>
・メモ一覧表示 </br>
・メモを作成する(本単位) </br>
・メモを作成する(プロジェクト単位) </br>
・メモを編集する </br>
・メモを削除する </br>
・メモを確認する</br>
