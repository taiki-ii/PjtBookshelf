#  プロジェクト名
社会人、学生のプロジェクト本棚メモ管理アプリ

【概要】
社会人、学生の自己課題（プロジェクト）の管理支援をします！
具体的には、
　自己課題である「プロジェクト」毎に「本棚」を作成して
　使用した「本」と「メモ」を管理します
【目的】
常に、作業に取り掛かりやすい状態を作る
【対象者】
社会人、学生
【対象物】
自己課題（技術学習、大学でのレポート作成、資格勉強、プレゼン作成、ポートフォリオ作成、学習発表、日々のスキル学習・・・）
【背景】
・小さな管理負担をなくして、作業に取り掛かりやすい状態を作りたいと考え、本アプリを作成開始しました！
・エンジニア歴1年経ち、研鑽のために個人開発を始めたいと思ったこと
（-マーカーを引いた箇所を見直すことが大変、メモを分類できない、引用で使用した本をすぐにコピペしたい等、
　　作業が増えるほど管理したいものが増えてしまいませんか？
   -小さな探しものが増えて、時間を消費してしまうことがよくありませんか？（私はよくあります・・・））

#   機能
■認証
・ログイン
・ログアウト
・ユーザー新規登録 
■プロジェクト
・プロジェクト作成 
・プロジェクト一覧表示 
・プロジェクト詳細表示 
・プロジェクト名変更 
・プロジェクト削除 
■本
・本を検索する   ※Google Books Api使用
・本をプロジェクトに登録 
・登録済み本を表示
・本の詳細表示
・本の削除 
■メモ
・メモ一覧表示 
・メモを作成する(本単位) 
・メモを作成する(プロジェクト単位) 
・メモを編集する 
・メモを削除する 
・メモを確認する
